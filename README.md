# Namaste React

A React learning project built while following the [Namaste React course](https://namastedev.com/learn/namaste-react).

The project is a restaurant discovery app called **Foodology**. It is being developed as I learn React, with topics and features added along the way.

## Run locally

Install the dependencies and start the Parcel development server:

```bash
npm install
npm start
```

Open the local URL printed in your terminal (usually `http://localhost:1234`).

## Build

```bash
npm run build
```
